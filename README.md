# IntelliCheck

IntelliCheck is a portfolio-ready text similarity playground for comparing documents and flagging potentially matching passages. It demonstrates a transparent, algorithm-first approach rather than presenting similarity as a final academic judgement.

## Included

- Normalized token comparison
- Jaccard similarity
- SequenceMatcher score
- CLI demo with two sample texts

## Run

```bash
python3 app.py
```

## Stack

Python 3 · standard library · text analysis

> This repository is a starter/demo implementation for portfolio exploration. Scores should be reviewed by a human before any formal decision.
